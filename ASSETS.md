# Character edit

The original character is retained at `public/images/reference-boy.png`.
The website uses the edited transparent PNG at `public/images/boy-no-earrings.png`.

Method: built-in image-generation tool, precise object edit.

Prompt: Remove both silver hoop earrings, including metal at the earlobes. Reconstruct the exposed earlobes naturally. Preserve the boy's hairstyle, face, expression, colors, lighting, framing, and 3D style. Keep a transparent background. No jewelry, text, or extra objects.

The other added 3D forms are CSS illustrations, animated with transforms. They are decorative, hidden from assistive technology, ignore pointer events, and stop animating when reduced motion is requested.
